## 🏗️ Architecture

### Backend (tRPC)
- `portugueseArabic.chatWithAvatar` - Unlimited AI chat
- `portugueseArabic.translate` - Portuguese-Arabic translation
- `portugueseArabic.transformText` - 5-level transformation
- `portugueseArabic.generateQuiz` - Quiz generation
- `portugueseArabic.generateGame` - Game generation
- `portugueseArabic.translateTunisianToPortuguese` - Dialect support

### Frontend (React 19)
- `PortugueseArabicChat.tsx` - Chat interface
- `PortugueseGamesQuizzes.tsx` - Games and quizzes

### Database
- User profiles and progress
- Learning history
- Quiz scores
- Game achievements
